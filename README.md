# РемБокс — наскрізний веб-проєкт (варіант 17)

Навчальний сайт сервісу ремонту техніки «РемБокс». Проєкт розвивається від лабораторної до лабораторної.

## Лабораторна робота №8 — Форми та localStorage

Додано обробку форми заявки на JavaScript і збереження користувацького стану у `localStorage`:
дані переживають перезавантаження сторінки.

Виконано:

- модуль `js/storage.js` — безпечні обгортки читання/запису `localStorage` (усе в `try/catch`, працює навіть у приватному режимі);
- модуль `js/form.js` — логіка форми заявки:
  - **автозбереження чернетки** полів під час введення (ключ `rembox_form_draft`) і її відновлення при поверненні;
  - **надсилання заявки** з перевіркою (`checkValidity` / `reportValidity`); збереження заявки у `localStorage` (ключ `rembox_orders`);
  - **повідомлення про успіх** і очищення чернетки після надсилання;
  - розділ **«Мої заявки»** — список збережених заявок із кнопкою «Видалити», що переживає перезавантаження;
- **збереження обраного** (ключ `rembox_favorites`): позначені послуги відновлюються після перезавантаження, лічильник оновлюється;
- дані зберігаються лише локально у браузері користувача й не передаються на сервер.

## Лабораторна робота №7 — Асинхронне завантаження та модулі

Дані каталогу винесено у `data/items.json`, JavaScript розділено на ES-модулі, додано стани «Завантаження»/«Помилка» з повторною спробою та відкладений пошук.

Виконано:

- `data/items.json` — 9 записів, 3 категорії, унікальні `id`;
- JS розділено на модулі: `api.js` (fetch), `render.js` (безпечний DOM), `utils.js` (debounce), `ui.js` (меню), `main.js` (entry);
- підключення одним модулем: `<script type="module" src="js/main.js">`;
- перевірка `response.ok` і обробка `try / catch / finally`;
- безпечне формування DOM через `createElement` і `textContent` (без `innerHTML`);
- стан «Завантаження», стан «Помилка» з кнопкою «Повторити»;
- відкладений пошук `debounce` 300 мс; пошук і фільтр за категорією діють разом; повідомлення «Нічого не знайдено».

## Лабораторна робота №6 — Динамічне формування DOM

Дані карток винесено у масив об'єктів, а статичні картки замінено динамічним рендерингом із пошуком і фільтром. Код у `js/scripts.js` (defer).

Виконано:

- масив `services` із 9 об'єктів і 3 категоріями; кожен об'єкт має `id`, `title`, `category`, `description`, `image`;
- `map()` для рендерингу, `filter()` для відбору, шаблонні рядки для розмітки;
- окрема функція `createCard(item)` і окрема `renderList(items)`;
- пошук без урахування регістру за назвою та описом;
- фільтр за категорією з варіантом «Усі»; пошук і категорія діють одночасно;
- повідомлення «Нічого не знайдено», якщо результат порожній;
- збереження послуг (обране) реалізовано делегуванням подій — працює для динамічних карток.

## Лабораторна робота №5 — JavaScript

Додано інтерактивність у окремому файлі `js/main.js`, підключеному з атрибутом `defer`. Інтерфейс змінюється через CSS-класи, а не inline-стилі.

Реалізовано три можливості:

- **Мобільне меню** — кнопка показує/ховає навігацію (`classList.toggle`, `aria-expanded`, `textContent`);
- **«Показати більше»** — розгортає/згортає додатковий текст у секції «Про сервіс» і змінює напис кнопки;
- **«Зберегти напрям»** — клік по кнопці картки перемикає стан «збережено» і оновлює лічильник збережених (`textContent`).

Використано `querySelector`/`querySelectorAll`, `addEventListener`, `classList`, `textContent`. Перевірено мишею й клавіатурою, помилок у консолі немає.

## Лабораторна робота №4 — SCSS і адаптивність

Стилі перенесено у SCSS і забезпечено коректне відображення на малих, середніх і великих екранах (mobile-first).

Виконано:

- робочу гілку `lab-4-scss-responsive`;
- `scss/main.scss`, `scss/_variables.scss`, `scss/_mixins.scss`, підключені правилом `@use` (не `@import`);
- у змінні винесено понад 5 повторюваних значень (кольори, відступи, радіус, точки переходу);
- вкладеність у кількох компонентах (`.card`, `.field`, `.main-nav`), зокрема `&` для станів `:hover` / `:focus-visible`;
- параметризовані міксини `respond-to($breakpoint)`, `grid($columns, $gap)`, `focus-ring($color)`, застосовані через `@include`;
- mobile-first макет із двома точками переходу (`$bp-tablet: 768px`, `$bp-desktop: 1024px`);
- адаптовано навігацію, сітку карток, форму, відступи й типографіку.

### Збірка SCSS → CSS

```bash
npm install sass          # одноразово
npx sass scss/main.scss css/styles.css --style=expanded
```

## Лабораторна робота №3 — Flexbox, Grid і форма

Удосконалено макет наявного контенту та додано тематичну форму заявки на ремонт (без SCSS, медіазапитів-новинок і JavaScript).

Виконано:

- робочу гілку `lab-3-layout-form` від актуальної основної гілки;
- **Flexbox** для одновимірних блоків (меню, поле форми, рядок дій `.form-actions`);
- **Grid** для двовимірних блоків (сітка карток `.cards`, сітка полів форми `.form-grid`);
- три однотипні картки з `gap`;
- тематичну форму з `label`, `input`, `select`, `textarea` і `button`;
- для кожного поля задано `id` і `name`, `label` зв'язано з полем через `for`;
- правила HTML-перевірки (`required`, `minlength`, `type="email"`, `type="tel"`, `pattern`) та стани `:focus-visible` і `:user-invalid`.

## Лабораторна робота №2 — CSS

Оформлено сторінку з ЛР1 засобами CSS, без зміни контенту та без JavaScript.

Виконано:

- створено й підключено `css/styles.css`;
- додано зрозумілі класи до основних частин сторінки (`site-header`, `main-nav`, `hero`, `button`, `card` тощо);
- визначено **9 CSS-змінних** у `:root`: основний колір (`--color-primary`), колір тексту (`--color-text`), фон сторінки (`--color-bg`), фон поверхонь (`--color-surface`), базовий відступ (`--space`) і радіус (`--radius`) та ін.;
- оформлено `body`, заголовки, абзаци, навігацію, посилання, кнопку та три однотипні картки видів ремонту;
- застосовано `margin`, `padding`, `border`, `border-radius`, `box-sizing: border-box`;
- реалізовано стани `:hover` і `:focus-visible` для посилань і кнопки;
- додано адаптацію під вузькі екрани (один медіазапит).
