# РемБокс — наскрізний веб-проєкт (варіант 17)

Навчальний сайт сервісу ремонту техніки «РемБокс». Проєкт розвивається від лабораторної до лабораторної.

## Лабораторна робота №2 — CSS

Оформлено сторінку з ЛР1 засобами CSS, без зміни контенту та без JavaScript.

Виконано:

- створено й підключено `css/styles.css`;
- додано зрозумілі класи до основних частин сторінки (`site-header`, `main-nav`, `hero`, `button`, `card` тощо);
- визначено **9 CSS-змінних** у `:root`: основний колір (`--color-primary`), колір тексту (`--color-text`), фон сторінки (`--color-bg`), фон поверхонь (`--color-surface`), базовий відступ (`--space`) і радіус (`--radius`) та ін.;
- оформлено `body`, заголовки, абзаци, навігацію, посилання, кнопку та три однотипні картки видів ремонту;
- застосовано `margin`, `padding`, `border`, `border-radius`, `box-sizing: border-box`;
- реалізовано стани `:hover` і `:focus-visible` для посилань і кнопки;
- додано адаптацію під вузькі екрани (один медіазапит).

### Запуск

Відкрити `index.html` у браузері або через локальний сервер:

```bash
python3 -m http.server 8000
# потім відкрити http://localhost:8000
```
